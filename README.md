# Оценка поиска рамок для документов

Небольшой прототип для проверки качества обнаружения двух областей в документах:

- регистрационный номер;
- блок электронной подписи.

Скрипт сравнивает координаты предсказаний бейзлайна с YOLO-разметкой и выводит precision, recall и средний IoU для совпавших рамок. Подробности по сопоставленным страницам записываются в CSV.

## Текущий статус и ограничения

Это исследовательский прототип, а не валидированный инструмент оценки. До использования метрик для выводов нужно проверить:

1. Что предсказания и эталон относятся к одним и тем же PDF/страницам и к одним и тем же областям.
2. Что имена в предсказаниях однозначно сопоставляются с именами изображений в YOLO-архиве.
3. Что координаты предсказаний и `image_size` заданы в пикселях той же страницы, что и эталон.
4. Что страницы эталона, отсутствующие в предсказаниях, тоже учитываются как пропуски (FN). В текущей версии это ещё не реализовано, поэтому recall может быть завышен.

Скрипт оценивает только локализацию двух рамок. Он не оценивает распознавание текста, корректность итогового PDF, установку штампа, интеграцию с API/КриптоПро или производительность сервиса.

## Формат входных данных

YOLO-архив должен содержать `obj.names` с классами `регистрационный номер` и `электронная подпись`, а также `.txt`-файлы разметки.

JSON с предсказаниями — массив записей (или одна запись) со следующими полями:

```json
[
  {
    "file": "document.pdf",
    "page": 1,
    "image_size": [1654, 2339],
    "dpi": 200,
    "reg_number_box": [175, 457, 836, 602],
    "signature_box": [577, 1703, 1088, 1947]
  }
]
```

Рамки задаются как `[x1, y1, x2, y2]` в пикселях, отсчёт слева сверху. Если рамка не найдена, укажите `null`.

Важно: имя из `file` должно сопоставляться с именем изображения в эталоне; одного одинакового номера страницы недостаточно, если соответствующие файлы имеют разные имена.

## Запуск

Требуется Python 3.9+; сторонние зависимости для оценщика не нужны.

```bash
python3 evaluate.py --gt /path/to/yololo.zip --pred /path/to/predictions.json
```

Необязательные параметры порогов IoU и пути CSV:

```bash
python3 evaluate.py --gt yololo.zip --pred predictions.json \
  --iou-reg 0.3 --iou-sig 0.5 --errors errors.csv
```

Порог IoU по умолчанию: 0.3 для регистрационного номера и 0.5 для подписи.

## Автоматическая подготовка разметки

`auto_markup.py` — отдельный прототип обработки PDF и создания черновых аннотаций. Для него нужна зависимость PyMuPDF:

```bash
python3 -m pip install pymupdf
python3 auto_markup.py --src /path/to/pdfs --out /path/to/output
```

Проверьте сгенерированные рамки вручную до использования аннотаций как эталона. При включении `--debug` нужен Pillow.

## Безопасность данных

В репозитории не следует хранить исходные PDF, размеченные документы, предсказания с персональными данными или другие материалы заказчика. Храните такие данные локально и передавайте только при наличии разрешения.
